# When Remainder explorer toggles, what happens to word-filters and pins?

Type: grilling
Map: [Remainder explorer spec](../map.md)

## Question

When Remainder explorer is turned on or off on Target show, what happens to the current AlterEgo word-filter selection (`selectedWords`) and to Remainder pins?

On and off cannot honestly share the same click meaning (filter vs letter-consumption). Decide whether entering the mode clears filter pills, whether leaving clears pins, and whether either set is restored if the user toggles back.
