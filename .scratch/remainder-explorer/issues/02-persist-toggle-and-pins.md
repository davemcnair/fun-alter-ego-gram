# Do Remainder explorer toggle and pins survive reload?

Type: grilling
Map: [Remainder explorer spec](../map.md)

## Question

Do the Remainder explorer toggle and the current pin set persist across a reload of Target show, and if so for which Target?

Target show already persists some filter checkboxes in `localStorage`. Decide what, if anything, survives reload: the toggle, the pins, both, or neither — and whether that state is per Target or global.
