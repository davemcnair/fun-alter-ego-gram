# What does Target show do when Remainder is empty?

Type: grilling
Map: [Remainder explorer spec](../map.md)

## Question

When Remainder is empty (pins consume the whole Target Signature), what does Target show show, and is Add word allowed?

Empty Remainder means there are no leftover letters to invent from. Decide the bag’s empty state, whether Add word is disabled, and whether that state is success (“all letters spoken for”) or a prompt to unpin.
